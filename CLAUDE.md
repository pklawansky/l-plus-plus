# L++ Project Instructions

## priorities.md

`priorities.md` is the source of truth for pending work. Keep it current:

- When starting work on an item, mark it **IN PROGRESS**
- When completing an item, mark it **DONE** with a one-line summary of what changed
- When discovering new work, add it in the correct priority tier
- Re-rank items if new information changes their relative value

Update `priorities.md` before ending any session where work was done.

## Design decisions

When brainstorming approaches, go with the recommended option unless the user explicitly redirects. Don't re-litigate choices that have already been approved.
